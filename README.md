# C Data Structures & Embedded Systems Suite

A collection of 5 modular C programs implementing core data structures and algorithms for embedded systems and network operations.

## Project Structure
- `question_one.c` - Embedded Device Event Logger (Doubly Linked List)
- `question_two.c` - Network Device Command Registry (Binary Search Tree & Audit Logging)
- `question_three.c` - Server Dependency Network Analyzer (Directed Graph & Adjacency Matrix)
- `question_four.c` - Emergency Medical Supply Routing (Weighted Graph & Dijkstra's Algorithm)
- `question_five.c` - Embedded Firmware Log Compression Utility (Huffman Coding)

## How to Compile and Run
Each module can be compiled independently using `gcc`. For example:

\`\`\`bash
# Compile and run Question 1
gcc -o question_one question_one.c -Wall
./question_one
\`\`\`
